Use in the monograph

It is designed to let the reader inspect how the reduced PIF system reproduces the qualitative logic of the IQG framework: thresholded activation, nonlinear structuring, bounded saturation, quantule-like persistence, restart behavior, and identity-like structure families.

Quantule detection

Detected quantules are defined here as local maxima above a chosen density threshold that persist for several frames. This is a reduced IQL-style behavioral detector, not yet a full manuscript classifier.

Identity / structure-family panel

Persistent quantule-like structures are grouped into recurring families using simple measurable features: peak density, persistence, compactness, local symmetry, and local flow/time intensity. This is a reduced ICE / IDL-style behavioral panel, not yet a final formal identity classifier.

Advanced parameter controls

These controls are mainly for deeper appendix exploration. The default preset is the recommended reader-facing configuration.

Interactive field view

Blue and orange show field intensity and ignition. Green overlays show candidate quantules that persist. In reinitiation mode, the run passes through emergence, decay, then restart.

Default view shows the recommended appendix configuration. Pause the run and drag the frame slider if you want to inspect a specific stage.

How to read this: PIF-a should remain smoother. PIF-b should show stronger nonlinear clustering. PIF-c should show the richest structured response. In reinitiation mode, a good REL-style run shows emergence, partial decay, then renewed activation. Detected quantules should appear as persistent local maxima rather than transient spikes. The family panel tells you whether these structures repeatedly separate into recognizable identity-like groups. For monograph use, the most informative default view is PIF-c with the anisotropic field and the balanced family classifier. This interactive link should therefore be cited in the appendix as a reader-oriented behavioral companion rather than as an independent quantitative validation instrument.
